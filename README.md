# 📚 Book Management System (MERN Stack)

A complete **Book Management System** built using the **MERN stack** — **MongoDB, Express, React, Node.js**, styled with **Tailwind CSS**.  
This project allows users to **Add, View, Update, and Delete (CRUD)** books easily with a clean and responsive UI.

---

## 🚀 Tech Stack

| Layer | Technology |
|--------|-------------|
| Frontend | React.js + Tailwind CSS |
| Backend | Node.js + Express.js |
| Database | MongoDB (Mongoose ORM) |
| Tools | Git, VS Code, Postman, npm/yarn |

---

## ⚙️ Features

✅ Add new books with title, author, and description  
✅ View all books from the database  
✅ Update existing book details  
✅ Delete unwanted books  
✅ Fully responsive UI (Tailwind CSS)  
✅ RESTful API architecture  
✅ MongoDB integration with Mongoose
